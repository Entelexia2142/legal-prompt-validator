# Legal Prompt Validator (Валидатор юридических промптов)

**Проект по промпт-инжинирингу в Legal Tech**

## 📌 О проекте

Инструмент для анализа и валидации юридических документов с помощью больших языковых моделей (LLM). Проект решает задачу контроля качества и минимизации "галлюцинаций" AI при работе с правовыми текстами.

## 🎯 Решаемая задача

При работе с кассационными жалобами, анализом переписки или расчётом ущерба LLM часто допускают ошибки: выдумывают несуществующие нормы, путают статьи или упускают важные доказательства.

**Наш инструмент проверяет:**
1. Соответствует ли ответ LLM заданной структуре (например, Markdown-таблице).
2. Содержит ли ответ ссылки на реально существующие нормы права (без "галлюцинаций").
3. Оценена ли в ответе достаточность доказательств.
