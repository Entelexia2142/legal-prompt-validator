# Промпт: Кросс-проектный анализ

## 🎯 Задача
Найти пересечения между параллельными судебными делами одного доверителя и создать синергию.

## 📝 Промпт
> «Ты — системный аналитик. Перед тобой два параллельных судебных дела одного доверителя: [краткое описание дела А] и [краткое описание дела Б]. 
> 1. Найди пересечения: общие участники (судьи, органы, эксперты), общие объекты недвижимости, общие документы.
> 2. Определи, какие аргументы и доказательства из дела А можно использовать в деле Б и наоборот.
> 3. Предложи 2–3 упреждающих действия, которые создадут синергию между делами.
> Оформи в виде таблицы: [Пересечение] | [Что использовать] | [Действие] | [Ожидаемый эффект].»
