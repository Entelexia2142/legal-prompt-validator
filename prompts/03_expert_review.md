# Промпт: Рецензирование судебной экспертизы

## 🎯 Задача
Найти методологические изъяны в заключении эксперта и подготовить вопросы для его допроса в суде.

## 📝 Промпт
> «Ты — ведущий эксперт-рецензент. Проанализируй текст судебной экспертизы по следующим критериям: 
1) Компетентность эксперта; 
2) Методологическая обоснованность; 
3) Полнота исследования; 
4) Наличие правовых оценок, выходящих за пределы компетенции. 
Составь список из 5-7 "каверзных" вопросов для допроса эксперта в суде, которые вскроют эти недостатки.»
