# Промпт: Генерация упреждающих действий

## 🎯 Задача
Превратить анализ последствий в конкретный план действий по управлению ситуацией.

## 📝 Промпт
> «Ты — стратег по управлению правовыми рисками. На основе анализа последствий (квадрата Декарта) для события [описание] предложи по 2-3 упреждающих действия для нейтрализации нежелательных последствий и усиления желательных. 
> Для каждого действия укажи: 
> 1. Тип (блокирующее/усиливающее/перенаправляющее/ускоряющее/страхующее). 
> 2. Срок исполнения. 
> 3. Ожидаемый эффект. 
> Оформи в виде таблицы: [Последствие] | [Тип действия] | [Действие] | [Срок] | [Эффект].»
