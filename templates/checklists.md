# Чек-листы проверки (шаблоны)

> Все шаблоны обезличены и могут использоваться для любых дел соответствующей категории.

## Чек-лист: коммунальный спор (договор водоснабжения)

### 1. Договорные отношения
- [ ] Определён способ заключения договора: письменный, конклюдентные действия (п. 3 ст. 434, ст. 438 ГК РФ)
- [ ] Собрана платёжная документация: периодичность, суммы, назначение платежа
- [ ] Установлена дата начала фактического потребления (первый платёж, показания приборов учёта)
- [ ] Проверено наличие/отсутствие лицевого счёта абонента и кому он оформлен
- [ ] Проверено, кто являлся собственником объекта на момент начала потребления (переход права — смена абонента)

### 2. Обязанности ресурсоснабжающей организации
- [ ] Установлен статус организации (МУП/АО/ООО) и её зона эксплуатационной ответственности
- [ ] Проверены основания отказа в подключении/переоформлении, указанные организацией (письменно)
- [ ] Запрошены сведения о разрешениях на строительство/ввод сетей (ответ уполномоченного органа — в материалах)
- [ ] Проверено, является ли отказ основаниями, предусмотренными Правилами подключения и Правилами холодного водоснабжения (ПП РФ № 644, № 2130)

### 3. Расчёты
- [ ] Расчёт водопотребления основан на нормативах потребления коммунальных услуг и/или приборах учёта (не на нормах проектирования сетей)
- [ ] Расчёт убытков от ограничения услуги основан на документально подтверждённых расходах (чеки, акты закупки)
- [ ] Проверены расчёты начислений организации за спорный период (двойное начисление, перерасчёт)

### 4. Процессуальные аспекты
- [ ] Определена подсудность (СПР, цена иска, имущественный/неимущественный характер требований)
- [ ] Соблюдён претензионный/досудебный порядок, если требуется для данной категории
- [ ] Определён круг лиц: организация, орган местного самоуправления, предыдущий собственник (при смене абонента)
- [ ] Проверена допустимость каждого письменного ответа органа как доказательства (относимость, допустимость, достоверность)

### 5. Ошибки ИИ, которые нужно проверить вручную
- [ ] Номера и редакции статей ЖК РФ, ГК РФ, ПП РФ — по первоисточнику (КонсультантПлюс/официальный портал)
- [ ] Не смешаны нормы ГПК и КАС (спор с организацией — ГПК; оспаривание действий органа — КАС, если публично-правовой характер)
- [ ] Не выдуманы судебная практика и разъяснения ВС РФ — каждая позиция проверена по первоисточнику

## Чек-лист: кросс-проектный анализ

### 1. Сквозные участники
- [ ] Составлен список органов власти, экспертов и лиц, фигурирующих более чем в одном деле
- [ ] Для каждого сквозного участника зафиксирована его процессуальная роль в каждом деле (не смешивать роли!)
- [ ] Проверено, не создаёт ли участие одного органа противоречащие позиции в разных делах

### 2. Ресурсные перекрёстки
- [ ] Выделены объекты недвижимости, фигурирующие в нескольких спорах
- [ ] Определён юридический эффект: как исход дела А влияет на предмет дела Б (и наоборот)
- [ ] Проверено, не противоречит ли позиция в одном деле позиции в другом (например, одновременное утверждение законности и незаконности одного объекта)

### 3. Информационные перетоки
- [ ] Составлен реестр документов, полученных в рамках каждого дела
- [ ] Для каждого документа определено: может ли он использоваться в другом деле как доказательство (относимость, допустимость)
- [ ] Документы, полученные в рамках одного дела, не выдаются как «установленные факты» в другом — только как доказательства, подлежащие оценке

### 4. Координация стратегии
- [ ] Согласованы сроки процессуальных действий по обоим делам (календарь контрольных дат)
- [ ] Проверено отсутствие процессуальных противоречий между ходатайствами в разных судах
- [ ] Убедились, что выбранная стратегия в каждом деле совместима с общей целью доверителя (а не «два фронта ради давления»)

### 5. Риски
- [ ] Оценён риск признания доказательств недопустимыми при переносе между делами
- [ ] Оценён риск раскрытия чувствительной информации при истребовании документов
- [ ] Оценён риск для третьих лиц от выбранной стратегии (соседние домовладения, другие абоненты)
